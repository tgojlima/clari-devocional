# 💜 Clari & Clau — Devocional da Mamãe e da Filha

Um aplicativo web lúdico e afetivo criado especialmente para acompanhar a jornada espiritual da Clarice (10 anos) e sua mãe, Claudia. Feito com muito amor, psicopedagogia e a cor favorita da Clari: Lilás! ✨

## 🎯 Sobre o Projeto

A pré-adolescência é uma fase cheia de novas emoções, amizades e transformações. Este aplicativo foi desenhado para ser o momento de pausa, conexão e palavra de Deus no fim do dia (10 a 15 minutinhos). 

O app traz **20 estudos devocionais** abordando temas cruciais desta fase de forma leve, usando metáforas dos universos que a Clari mais ama (Disney, Pixar, Animes, Roblox e mais!). 

## ✨ Funcionalidades

- **📱 Interface Lúdica e Comic:** Design estilo quadrinhos, com avatares personalizados e muito lilás.
- **📚 20 Dias de Estudos (Segunda a Sexta):** Devocionais temáticos (Divertidamente, Moana, Haikyuu, Spy x Family, etc.).
- **⏱️ Cronômetro Integrado:** Para conduzir o tempo sem pressa (15 minutos).
- **📝 Nossas Anotações Secretas:** Espaço para a Clari e a Mamãe registrarem o que Deus falou. Tudo é salvo localmente no navegador!
- **🏅 Sistema de Progresso:** Medalhas e selos para celebrar a constância na semana.
- **🖼️ Emojis e Avatares Dinâmicos:** Os personagens favoritos ilustram a reflexão de cada dia!
- **🌐 Funciona Offline:** Configurado como um PWA (Progressive Web App) para ser instalado no celular e usado sem internet.

## 🛠️ Tecnologias Utilizadas

- **HTML5, CSS3 e JavaScript puro:** Código limpo e rápido, sem dependências pesadas.
- **PWA (Progressive Web App):** Service Workers e Manifest configurados.
- **LocalStorage:** Banco de dados seguro e local, garantindo a privacidade das meninas.
- **Fonte:** Google Fonts (*Comic Neue* e *Baloo 2*).
- **Ícones:** FontAwesome.

## 🚀 Como usar (Modo Offline / Instalação)

1. Acesse o link oficial do aplicativo via Netlify ou GitHub Pages.
2. No celular/tablet, abra o navegador e selecione a opção **"Adicionar à Tela Inicial"**.
3. O app será instalado no seu dispositivo.
4. Ao abrir, o app detectará o dia da semana atual automaticamente. Selecione "Começar o Devocional de Hoje"!
